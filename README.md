MIGO - LANDING PAGE
===================

Archivos
  index.html   -> la estructura y los textos de la página
  style.css    -> colores y diseño
  script.js    -> los 4 videos (lista VIDEOS al principio) y las animaciones
  assets/      -> logos (y las imágenes que quieras sumar)

Para ver la página en tu compu: hacé doble clic en index.html.

Cargar los videos (script.js, lista VIDEOS arriba de todo)
  - YouTube: pegá solo el ID. En https://youtu.be/-p172RAAT_s el ID es -p172RAAT_s
  - Spline: pegá el link público (en Spline: Export > Public URL)
  - Si dejás el espacio vacío se muestra "Próximamente".
  - Ahora el video que pasaste está en el primer lugar ("Realidad virtual").
    Si es de otro tipo, movelo al lugar que corresponda.

Cambiar el Instagram
  En index.html, al final, buscá el botón "Instagram" y reemplazá href="#" por tu link.

Publicarla en Vercel
  1. Subí esta carpeta a un repositorio nuevo de GitHub (Add file > Upload files).
  2. En vercel.com: Add New > Project > elegí el repositorio > Deploy.
  3. Cada cambio que subas a GitHub se actualiza solo.
